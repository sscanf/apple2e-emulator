# Disk II sounds

Drive recordings: `Spin_Sound.wav` (motor, played in a loop),
`Read_1_Sound.wav` / `Read_2_Sound.wav` (head steps) and
`Grunt_Grind_1_Sound.wav` / `Grunt_Grind_2_Sound.wav` (head hitting the
track 0 stop during recalibration).

`Floppy_Eject_Sound.wav`, played when a disk is ejected, is cut from
["removing_floppy_disc.wav"](https://freesound.org/s/39702/) by
[KRAFTWERK2K1](https://freesound.org/people/KRAFTWERK2K1/), released into
the public domain (CC0).

The other recordings were downloaded from a website offering them as free to
use; the original source could not be identified. The file names match those
used by the *Apple 2 Disk Drive Sound Simulator*. They are **not** covered
by this project's MIT license. If you hold the rights to these recordings
and want them credited differently or removed, please open an issue.

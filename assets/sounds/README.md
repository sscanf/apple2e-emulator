# Disk II sounds

`motor.wav`, `step1.wav`, `step2.wav` and `grind.wav` are cut from
["Apple IIe Computer Boot and Load a ProDOS 5.25" Disk"](https://freesound.org/s/388192/)
by [SavageFX](https://freesound.org/people/SavageFX/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Changes: converted to mono 16-bit 44.1 kHz, the steadiest 2 s of the motor
made into a loop, and the boot-time recalibration hits cut out (the
recording has no isolated head steps, so `step1`/`step2` are shortened,
quieter recalibration hits). See `tools/extract_drive_sounds.py`.
